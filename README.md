# My-web-OS
This is a git repo for my stardance project My WebOS.
My Custom WebOS
A browser comptaible web operating system built for the Stardance WebOS mission.  It features a dekstop environment with  loki background. It has 3 apps with icon (About me, Notes and a Calculator). It has a live clock and a toolbar.

It also has a working maximize/ minimize system.
